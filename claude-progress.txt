## 既知の限界(許容している)
- Go API にレート制限がない。JWT は退会後も最大 5 分有効で、その間の PUT /me/profile が行を作り直す
- 宛先ごとの制限は、他人のログインを妨害するのに使える(+ のエイリアスは別に数える)
- CSP の退行(静的なページを足すと nonce が付かず止まる)を自動では検知できない
- Cron の DELETE に件数の上限がなく、CRON_SECRET の最小長も強制していない
- 見送ったレビュー指摘: encryptOAuthTokens と storeToken: "hashed"、メール HTML の URL のエスケープ
- Vercel のプレビューのビルドは失敗する(環境変数が Production だけ。使わない方針)
- 無料プランの Render はスリープする。スリープ明けの初回は 5 秒で切れて bio が出ないことがある
